# Foodget

Foodget adalah website makanan dan minuman dengan konsep e-commerce sederhana yang dikembangkan untuk memenuhi tugas kuliah pada semester 2. Website ini memungkinkan pengguna melihat produk dan mengelola pesanan melalui keranjang.

## Fitur

* Beranda— Menampilkan halaman utama Foodget.
* Daftar Makanan — Menampilkan berbagai pilihan makanan.
* Daftar Minuman — Menampilkan berbagai pilihan minuman.
* Keranjang — Menambahkan dan mengelola produk yang dipilih.
* Login & Logout — Sistem autentikasi pengguna.
* Diskon — Menampilkan informasi diskon pada produk.
